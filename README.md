# api_final
Завершаем наш учебный проект – социальную сеть, позволяющую пользователям делиться контентом, оставлять комментарии и подписываться на других пользователей. Проект реализован на передовых технологиях: Python 3.7, Django 2.2, DRF и JWT. Для запуска выполните следующие шаги: склонируйте репозиторий, настройте виртуальное окружение, установите все необходимые библиотеки, примените миграции и запустите Django-сервер. Подробная инструкция по развертыванию находится в репозитории.
